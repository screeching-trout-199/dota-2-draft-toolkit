# Dota 2 Draft Toolkit — feature reference

Start with hero groups, organize team compositions, and keep match notes close at hand. These are the main areas covered by Dota 2 Draft Toolkit.

| Section | Description |
|---|---|
| Hero groups | Character or team groups presented with the context needed to organize a session. |
| Team compositions | Character or team groups presented with the context needed to organize a session. |
| Match notes | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
